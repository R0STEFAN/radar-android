# 📡 Fluger Radar Android (Флюгер Радар)

Автономний мобільний застосунок Android для тактичного моніторингу повітряного простору України та завчасного виявлення загроз (Шахеди, КАБи, крилаті та балістичні ракети, розвідувальні БПЛА).

[![Build & Release Android APK](https://github.com/R0STEFAN/radar-android/actions/workflows/build-apk.yml/badge.svg)](https://github.com/R0STEFAN/radar-android/actions/workflows/build-apk.yml)

---

## 🎯 Основні можливості

1. **Пряме з'єднання (Direct Connection — без проксі):**
   - Працює напряму з України через захищене TLS-з'єднання з `radar.quick.ua` та `map.ukrainealarm.com`.
2. **24/7 Фонова служба (ForegroundService + WakeLock):**
   - Відстеження цілей та розрахунок векторів зближення працює навіть при вимкненому екрані або закритому інтерфейсі.
   - Автоматичний перезапуск після перезавантаження смартфона (`RECEIVE_BOOT_COMPLETED`).
3. **Захист від РЕБ та GPS-спуфінгу (Анти-Ліма):**
   - Головний режим — ручне закріплення точки спостереження на карті, збережене в локальній пам'яті (`SharedPreferences`).
   - При використанні кнопки "Оновити по GPS" спрацьовує географічний валідатор кордонів України ($44.0^\circ - 52.5^\circ\text{N}, 22.0^\circ - 40.5^\circ\text{E}$). Якщо під дією РЕБ координати стрибають у Ліму (Перу) або закордонні аеропорти, додаток блокує стрибок і попереджає користувача.
4. **Два незалежних канали сповіщень:**
   - 🚨 **Критична тривога (Курс на вас):**
     - Спрацьовує, якщо ціль знаходиться в радіусі загрози (15–45 км, налаштовується) і її вектор руху спрямований безпосередньо у вашу сторону ($\Delta\theta \le 45^\circ$).
     - Власний перемикач (ВКЛ / ВИКЛ).
     - Звук за замовчуванням: синтезована повітряна сирена Флюгер (920 ↔ 640 Hz).
     - Підтримка вибору власного рингтону чи аудіофайлу.
   - 🟡 **Спостереження сектора:**
     - Інформаційне сповіщення про наявність повітряних цілей у радіусі спостереження: вибір між **45 км** (Місто / Тактичний щит) та **80 км** (Район / Ешелоноване ППО).
     - Окремий незалежний перемикач (ВКЛ / ВИКЛ).
     - Звук за замовчуванням: тактичний подвійний сонар (880 Hz), що запобігає плутанню зі звичайними сповіщеннями месенджерів (Telegram, Signal, Viber).
     - Підтримка вибору власного звуку.
5. **Крос-сенсорна фузія:**
   - Поєднання радіолокаційних променів Флюгера та офіційних векторних треків Мінцифри/Повітряних Сил.

## 🛠️ Архітектура додатку

- **Native Core (Kotlin):**
  - `ThreatAnalyzer.kt`: Гаверсинусна кінематика, розрахунок кутів пеленгу, часу підльоту (ETA), фільтрація РЕБ.
  - `RadarApiClient.kt`: Генерація фібоначчі-підпису та запити до `radar.quick.ua`.
  - `CentrifugeMapDecoder.kt`: Демаскування Xorshift32 PRNG, FNV-1a хешування, LEB128 AST та десеріалізація Centrifugo fallback потоку Мінцифри.
  - `UkraineAlarmClient.kt`: Опитування Centrifugo потоку `map.ukrainealarm.com`, перетворення проекції Меркатора та зсувів маркерів для треків Мінцифри.
  - `RadarForegroundService.kt`: Фоновий цикл опитування кожні 5 секунд, управління Notification Channels, запобігання спаму (debounce).
  - `WebAppInterface.kt`: Шлюз взаємодії між JavaScript і Kotlin.
- **Tactical UI (WebView + Leaflet):**
  - Офлайн-бандл Leaflet (без зовнішніх CDN).
  - Темна тактична карта CartoDB з кільцями радіусів та іконками загроз.
  - Нижня шторка (Bottom Sheet) для швидкого налаштування радіусів та звуків.

## 📦 Автоматична збірка APK (GitHub Actions CI)

При кожному `git push` у гілку `main` на GitHub запускається автоматичний workflow `.github/workflows/build-apk.yml`, який:
1. Збирає релізний APK (`./gradlew assembleRelease`).
2. Створює реліз у розділі **[Releases](https://github.com/R0STEFAN/radar-android/releases)** з готовим для завантаження файлом `app-release.apk`.
